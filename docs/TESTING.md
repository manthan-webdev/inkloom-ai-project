# Manual tests
Navigation: every sidebar link opens. Audit: load Social Media sample, run, expect a claim finding "Needs verification". Filters: category/severity narrow the list. Suggestions: edit, apply, text replaced only at that phrase; re-run. Assistant: select a finding, open assistant, prompts reference it; "Apply to draft" needs a click. Review: submit, switch to Reviewer, approve/request changes (comment required). History: entries per action with snapshots. Persistence: refresh keeps data. Empty states: reset, check insights. Responsive: narrow the window. Automated tests: none; build verified with `npm run build`.
